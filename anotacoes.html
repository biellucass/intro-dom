Conhecendo a DOM

O que é o DOM?

DOM significa Document Object Model.

É uma representação do documento HTML em forma de objetos, organizada em uma estrutura hierárquica de árvore, conhecida como DOM Tree.

Note que cada elemento do HTML está conectado. Chamamos esses elementos de nó(node) dentro dessa estrutura.

Em outras palavras, o navegador basicamente transforma o HTML em uma estrutura que o JavaScript consegue acessar e manipular.

Pra que serve o DOM?

O DOM permite que o JavaScript intereja com os elementos HTML. Exemplos:

  • Selecionar elementos : Encontrar um botão
  • Alterar conteúdo : Alterar um título, aplicar bordas e etc
  • Alterar estilos : Mudar cores, aplicar bordas e etc
  • Criar elementos : Criar paragráfos, listas, links e etc
  • Remover elementos : Excluir itens criados e já existentes
  • Capturar eventos : Detectar cliques, teclas pressionadas etc
  • Modificar atributos: Alterar um src, um aria-label e etc.
