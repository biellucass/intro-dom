# 🌳 Estudos e Práticas com o DOM (Document Object Model)

Repositório dedicado aos estudos práticos sobre a manipulação do **DOM** utilizando **JavaScript**, **HTML** e **CSS**. Aqui estão concentrados conceitos fundamentais para conectar scripts JavaScript à estrutura visual das páginas web.

---

## 🚀 O que você encontra neste repositório

* **Seleção de Elementos:** Como capturar elementos da página (`getElementById`, `querySelector`, `querySelectorAll`).
* **Manipulação de Conteúdo e Atributos:** Alteração de textos, valores de inputs e atributos HTML (`textContent`, `innerHTML`, `setAttribute`).
* **Manipulação de Estilos e Classes:** Adição, remoção e alternância de classes CSS de forma dinâmica (`classList.add`, `classList.toggle`).
* **Eventos (Event Listeners):** Como escutar interações do usuário (cliques, digitação, envio de formulários) com `addEventListener`.
* **Criação e Remoção de Elementos:** Inserção dinâmica de novos elementos na árvore do DOM (`createElement`, `appendChild`, `remove`).
